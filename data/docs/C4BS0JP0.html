C4BS0JP0Déshabillage - Habillage : Volet
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel : Extracteur de bras d’essuie-vitres FACOM U.14A.
2. Déshabillage
Figure : c4bs05wd
Déposer l’ensemble bras-balai d’essuie-vitre (1) ; À l’aide de l’outil FACOM U.14A.
Figure : c4bs05xd
Déposer :
  • Le 3ème feu de stop (7) (voir opération correspondante)
  • Les vis (9)
  • Le becquet de volet arrière (5) (suivant option)
  • Le support cordon de tablette (10) (chasser l’axe central)
  • Les garnitures supérieures latérales (11), (8), (4), (6) de volet arrière
  • La vis (2)
  • La garniture inférieure de volet (3)
Figure : c4bs05yd
Déposer les vis (14).
Déclipper :
  • Les éclaireurs de plaque de police (12)
  • Le contacteur d’ouverture de volet arrière (13)
  • Les agrafes (18)
Déconnecter :
  • Les éclaireurs de plaque de police (12)
  • Le contacteur d’ouverture de volet arrière (13)
  • Le mécanisme d’essuie-vitre (20)
  • La serrure (21)
Désaccoupler le tuyau lave-vitre (16).
Percer les rivets  (en "a") ; À l’aide d’un foret Ø 8 mm.
Déposer :
  • Le moteur d’essuie-vitre (20)
  • La serrure (21)
  • Les éclaireurs de plaque de police (12)
  • Les écrous (19)  (plastique)
  • Le faisceau électrique (17)
  • Le gicleur de lave-vitre (15)
Déposer la vitre de volet arrière  (voir opération correspondante).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
NOTA : Serrer les vis (9) à 0,6 m.daN .
