C4BG0VP0Dépose - repose : Volet arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. Volet arrière (Complet)
Figure : c4bg0tvd
Dégrafer partiellement le joint d’entrée de coffre (1).
Déposer :
  • La ceinture de sécurité arrière (3) (partiellement)
  • La garniture de custode (2)
Figure : c4bg0twd
Déconnecter le connecteur (4).
Figure : c4bg0txd
Déposer le troisième feu de stop (9) (voir opération correspondante).
Désaccoupler le tuyau de lave-vitre (8).
Dégager le faisceau électrique (10).
Déclipper les équilibreurs de volet arrière (7) (en "a").
ATTENTION : Opérations nécessitant deux opérateurs.
Déposer :
  • La vis (6)
  • Le volet (5)
1.2. Volet arrière déshabillé
Déshabiller le volet arrière (voir opération correspondante).
Dégager le faisceau électrique (10).
Déclipper les équilibreurs de volet arrière (7) (en "a").
Figure : c4bg0tyd
ATTENTION : Opérations nécessitant deux opérateurs.
Déposer :
  • Les vis (6)
  • Le volet arrière (5)
Figure : c4bg0tzd
NOTA : Pour déposer le volet avec ses charnières ; Dégager légèrement la garniture de pavillon .
Déposer l’écrou (11) (de chaque côté).
2. Repose
IMPERATIF : Lors d’un remplacement de volet ou de mise en peinture du volet déposé, appliquer un cordon d’étanchéité (indice "A1") sur le sertissage inférieur du volet en veillant à fermer les extrémités.
IMPERATIF : Mise en peinture, puis pulvérisation dans les corps creux, du produit indice "C5" dans la zone de réparation.
Procéder dans l’ordre inverse des opérations de dépose.
Couple de serrage :
  • Serrer les vis (6) à 3,2 ± 0,8 m.daN
  • Serrer l’écrou (11) à 1,5 ± 0,4 m.daN
