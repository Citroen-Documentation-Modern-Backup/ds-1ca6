C5JS010SP0Déshabillage - Habillage : Pare-chocs avant
DEPUIS OPR 11436
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage préconisé
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350.
2. Opération préliminaire
Déposer le pare-chocs avant .
3. Déshabillage
Déposer :
  • La plaque de police
  • Les lave-projecteurs  (suivant équipement)
  • Les feux de brouillard avant  (suivant équipement)
Figure : c4am0vhd
NOTA : Chasser les clous de rivets avant le perçage ( de chaque côté).
À l’aide d’une perceuse équipée d’un foret ø 4 mm, faire sauter les rivets (1) ( de chaque côté).
Déclipper : Le renfort de pare-chocs (2) ( en "a") ; À l’aide de l’outil [1].
Dégager : Le renfort de pare-chocs (2).
Percer les corps de rivets restants ( de chaque côté).
Déposer : Le renfort de pare-chocs (2).
Figure : c4am0vjd
Opération symétrique :
  • Déposer les vis (3)
  • Déclipper la garniture (4) ( en "b") ; À l’aide de l’outil [1]
  • Déposer la garniture (4)
Figure : c4am0vkd
Déclipper la calandre (5) ( en "c") ; À l’aide de l’outil [1].
Déposer la calandre (5) (Sur un établi).
NOTA : La calandre (5) est composée d’une grille et d’un enjoliveur chromé (suivant équipement).
Figure : c4am0vld
Déclipper l’enjoliveur chromé (6) ( en "d") ; À l’aide de l’outil [1].
Déposer :
  • La grille (7)
  • L’enjoliveur chromé (6)
Figure : c4am0vmd
Déclipper les chevrons (8) sur la grille (7) ( en "e") ; À l’aide de l’outil [1].
Déposer : Les chevrons (8).
Figure : c4am0vnd
Opération symétrique :
  • Déclipper l’enjoliveur (9) ( en "f") ; À l’aide de l’outil [1]
  • Déposer l’enjoliveur (9)
Figure : c4am0vpd
Déclipper : Le déflecteur (11) ( en "g") ; À l’aide de l’outil [1].
Déposer :
  • Le déflecteur (11)
  • La peau de pare-chocs (10)
4. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
Reposer :
  • Les feux de brouillard avant  (suivant équipement)
  • Le pare-chocs avant
Vérifier le fonctionnement des différents équipements.
